# Releases

Reason CLI ships often, usually several times a week. Every version is published to npm:

- All versions: https://www.npmjs.com/package/@reason-machines/cli?activeTab=versions
- Installed version: `reason --version`
- Check for an update: `reason update --check`
- Install the latest: `reason update`

To pin a release with npm, append its version:

```sh
npm install -g @reason-machines/cli@0.2.221
```
